## Workflow
**Ideas → Research → Planning → In Progress → Testing → Completed**, with **On Hold** for paused work.

Track initiatives on the [Project Aegis R&D Board](https://github.com/users/k41ju0x/projects/3/views/1). Use [ROADMAP.md](ROADMAP.md) for milestones and [the project template](templates/PROJECT-TEMPLATE.md) to record decisions, equipment, tests, and lessons learned.

## Hybrid Visibility Model
**Public:** sanitized objectives, progress, architecture summaries, reproducible demonstrations, and lessons learned.  
**Private:** sensitive infrastructure details, credentials, confidential research artifacts, non-public findings, and secrets.

Read [SECURITY.md](SECURITY.md) before contributing information.

## Existing Flagship Project
**[Project NEXUS](https://github.com/k41ju0x/Project-NEXUS)** remains an independent home lab repository. Project Aegis links to it without moving or modifying its contents.
