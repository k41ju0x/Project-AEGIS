# AEG-002 — Meshtastic

**Domain:** LoRa / off-grid mesh networking  
**Status:** Planning (provisional)

## Goal
Design, build, configure, and field-test a documented Meshtastic node, starting with a portable device and potentially expanding to a network of nodes.

## Decisions to make
- Form factor: compact, rugged field, or fixed infrastructure node
- Hardware and RF band compatible with local regulations
- Battery runtime, power management, antenna, enclosure
- Bluetooth / GPS / telemetry requirements
- Test plan: message delivery, coverage, SNR/RSSI, runtime

## Next action
Choose a hardware platform and draft a bill of materials.

Never transmit with an unsuitable antenna or publish sensitive location and channel secrets.
